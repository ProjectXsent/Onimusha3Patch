# Onimusha3Patch

1. Patch Onmimusha 3 to allow any screen resolution.
2. Fix the Configure input menu (see Configure input patch directory).

## How to use

1. Download the [latest release](https://github.com/ProjectXsent/Onimusha3Patch/releases/latest).
2. Extract/copy `dsound.dll`, `Oni3Patch.dll` and `Oni3Patch.ini` to Onimusha 3 game directory.
3. Run `Oni3.exe`.

Optional: 
- [Game update v1.2.0.0](https://community.pcgamingwiki.com/files/file/4144-onimusha-3-demon-siege-widescreen-fix/)
- [Controller Support](https://github.com/ProjectXsent/onimusha3-gamepad-fix)
